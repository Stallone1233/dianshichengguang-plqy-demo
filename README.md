# 点石成光 · 钙钛矿量子点 PLQY 预测 Demo

第十五届中国创新创业大赛 AI+OPC 创新应用专业赛 · 「AI+原生技术与科学创新类」

输入一组配方与工艺参数（体系、溶剂、配体、合成方法、温度、时间），
输出预测荧光量子产率（PLQY）、90% 预测区间，以及每个特征对本次预测的贡献（TreeSHAP）。

---

## 这个模型能做什么，不能做什么

**能**：判断趋势——同一体系下提高温度是拉高还是拉低 PLQY，换溶剂影响多大。

**不能**：替代实验。按文献分组交叉验证 **R² = −0.127**，留出集 **R² = −0.686**，
**均低于「直接用中位数预测」的基线**。页面里每个结果都带 90% 区间，
区间往往很宽，这是真实状态，不是界面缺陷。

原因写在项目文档里，一句话：文献里能拿到的工艺字段太少
（温度覆盖 17.4%、前驱体比 0%、配体用量 0%），加上同一批样品在不同文献里的
量子产率口径不一致（overall vs excitonic 可差一个数量级）。

**一个诚实的负结果，好过一个包装过的正结果。**

## 特征口径

只允许「实验前可以设定的量」进特征，**不用波长、稳定性等结果量，否则就是用答案预测答案**。

| 类别特征 | 数值特征 |
|---|---|
| 体系（CsPbCl₃ / CsPbBr₃ / CsPbI₃ / mixed / other） | 温度 °C |
| 合成方法族（hot_injection / LARP / post_exchange / solid_state / …） | 反应时间 min |
| 溶剂族 | 配体用量 |
| 配体族 | 前驱体比 |

明确排除：`emission_nm`、`stability_desc`、`plqy_method`。
